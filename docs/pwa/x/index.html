Když je režim standalone, Chrome spouští starou nainstalovanou PWA. Bývá v chrome://apps.

  1. Do adresního řádku Chrome napiš chrome://apps a odstraň Windmi.
  2. Nebo: Chrome → ⋮ → Nastavení → Aplikace.
  3. Pak klepni níž na vymazání cache.
